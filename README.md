# ShafieeDocAI

Persian Document Intelligence AI.

## Goal

Develop original machine-learning models to understand
Persian invoices and other Persian documents.

## Principles

- Develop and train our own models.
- Avoid third-party AI inference APIs.
- Build reproducible datasets and experiments.
- Evaluate every model with tests and metrics.
- Support offline inference as a long-term goal.

## Initial Target

Persian printed invoice recognition and field extraction.

## Technology

- Python
- PyTorch (planned)
- .NET integration (planned)
